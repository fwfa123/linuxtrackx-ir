# Feature 0003: Centralized Version Management

## Description

Centralize version management to a single source of truth and implement a Help|About dialog as the primary location for users to view version information. This will eliminate version inconsistencies across the application and ensure the AppImage build process automatically picks up the correct version.

## Current State Analysis

### Version Display Locations Found:
1. **Main GUI (`ltr_gui.cpp:89`)**: `setWindowTitle(QStringLiteral("Linuxtrack GUI v") + QStringLiteral(PACKAGE_VERSION))`
2. **Mickey GUI (`mickey.cpp:815`)**: `setWindowTitle(QString::fromUtf8("Mickey v")+QString::fromUtf8(PACKAGE_VERSION))`
3. **Wii Server (`wii_server.cpp:23`)**: `setWindowTitle(QString("Linuxtrack Wii server v")+PACKAGE_VERSION)`
4. **Welcome Page (`help/welcome.htm:11`)**: Hardcoded `v0.99.23` in HTML content
5. **AppImage Config (`scripts/appimage/v2/config.sh:23`)**: Hardcoded `VERSION="0.99.25"`

### Version Source:
- Primary source: `configure.ac:5` - `AC_INIT([LinuxTrack],[0.99.24],[...])`
- Generated: `config.h` contains `PACKAGE_VERSION` macro
- Inconsistency: Multiple hardcoded versions exist

## Implementation Details

### Version Extraction Script
```bash
# In scripts/appimage/v2/config.sh
extract_version() {
    local configure_ac="$PROJECT_ROOT/configure.ac"
    if [[ -f "$configure_ac" ]]; then
        VERSION=$(grep 'AC_INIT.*\[.*\],\[\([^]]*\)\]' "$configure_ac" | sed 's/.*\[\([^]]*\)\].*/\1/')
        if [[ -z "$VERSION" ]]; then
            die "Could not extract version from configure.ac"
        fi
    else
        die "configure.ac not found at $configure_ac"
    fi
}
```
