# Feature Plan: Alternative MFC42.dll Sources for Users Without Wine32

## Context
The current Mfc42uWinetricksExtractor relies primarily on winetricks to install mfc42.dll, which fails for users on Arch Linux with only wow64 (no wine32) since winetricks 64-bit doesn't have the mfc42 option or fails to install it. This feature adds alternative sources and extraction methods to the sources_mfc42.txt file to provide fallback options for these users.

**Final Goal**: Ensure that a copy of `mfc42.dll` (and `mfc42u.dll` if needed) ends up in the user's `~/.config/linuxtrack/tir_firmware/` folder for the 32-bit winebridge component.

**Current Issue**: The winebridge NSIS installer (`check_data.c`) currently only creates a symlink for `mfc42u.dll` but not for `mfc42.dll`. Both DLLs need symlinks created.

**DLL Clarification**: 
- `mfc42.dll` = ANSI version of Microsoft Foundation Classes library
- `mfc42u.dll` = Unicode version of Microsoft Foundation Classes library
- Both are typically needed for full compatibility with older applications

## Technical Requirements

### Current Implementation Analysis
The existing `Mfc42uWinetricksExtractor` class in `extractor.cpp` (lines 566-1608) currently:
- Uses `sources_mfc42.txt` to read download URLs
- Attempts winetricks installation first (preferred method)
- Falls back to direct download and extraction via Wine
- Uses cabextract to extract DLLs from Microsoft installers

### Alternative Sources Identified from Winetricks Analysis

#### Primary Alternative Sources (in order of preference):

1. **VS6SP6.EXE (Visual Studio 6 Service Pack 6)**
   - URL: `https://www.ddsystem.com.br/update/setup/vb6+sp6/VS6SP6.EXE`
   - SHA256: `7fa1d1778824b55a5fceb02f45c399b5d4e4dce7403661e67e587b5f455edbf3`
   - Contains: mfc42.dll, mfc42u.dll, msvcirt.dll, msvcp60.dll, msvcrt.dll, oleaut32.dll, olepro32.dll
   - Extraction method: cabextract to extract vcredist.exe, then cabextract vcredist.exe

2. **VC6RedistSetup_deu.exe (German version)**
   - URL: `https://download.microsoft.com/download/vc60pro/Update/2/W9XNT4/EN-US/VC6RedistSetup_deu.exe`
   - SHA256: `c2eb91d9c4448d50e46a32fecbcc3b418706d002beab9b5f4981de552098cee7`
   - Contains: mfc42.dll, mfc42u.dll, msvcirt.dll, msvcp60.dll, msvcrt.dll, oleaut32.dll, olepro32.dll
   - Extraction method: Wine installer with /T parameter, then cabextract

3. **Direct DLL Download Sources** (Fallback)
   - DLL-files.com: `https://www.dll-files.com/mfc42.dll.html`
   - DLLme.com: `https://www.dllme.com/dll/files/mfc42`
   - Note: These provide direct DLL downloads but require verification of authenticity

#### 3. `src/qt_gui/extractor.cpp`
Modify the `Mfc42uWinetricksExtractor` class to handle the new extraction methods:

**New Methods to Add:**
- `bool extractFromVS6SP6(const QString &installerPath)` - Handle VS6SP6.EXE extraction
- `bool extractFromVC6RedistSetup(const QString &installerPath)` - Handle VC6RedistSetup_deu.exe extraction
- `bool downloadDirectDLL(const QString &sourceUrl)` - Handle direct DLL downloads from third-party sources

**Modify Existing Methods:**
- `downloadVCRedist()` - Update to parse new source format with extraction method
- `commenceExtraction()` - Add logic to choose extraction method based on source type
- `cabextractFinished()` - Handle different extraction stages for VS6SP6

**Extraction Algorithm for VS6SP6.EXE:**
1. Download VS6SP6.EXE to cache directory
2. Use cabextract to extract vcredist.exe from VS6SP6.EXE: `cabextract -d "${TMP}" -F vcredist.exe "${CACHE}/VS6SP6.EXE"`
3. Use cabextract to extract DLLs from vcredist.exe: `cabextract -d "${TMP}" "${TMP}/vcredist.exe"`
4. Copy extracted DLLs to system32 directory
5. Rename atla.dll to atl.dll (as per winetricks implementation)
6. **Copy mfc42.dll and mfc42u.dll to ~/.config/linuxtrack/tir_firmware/**

**Extraction Algorithm for VC6RedistSetup_deu.exe:**
1. Download VC6RedistSetup_deu.exe to cache directory
2. Use Wine to run installer with /T parameter: `wine VC6RedistSetup_deu.exe /T:c:\\ /Q`
3. Use cabextract to extract DLLs from extracted vcredist.exe
4. Copy DLLs to system32 directory
5. **Copy mfc42.dll and mfc42u.dll to ~/.config/linuxtrack/tir_firmware/**
