Wine reference

For day-to-day Wine Bridge setup, use the Gaming tab in ltr_gui: install TrackIR firmware and MFC42 as prerequisites, then use Install Wine Bridge for Lutris, Steam Proton, or a custom Wine prefix. Detailed firmware extraction steps are in the Firmware and Wine bridge guide.

This page keeps command-line notes and prefix details for when the Gaming tab is not enough. The Wine bridge (NPClient.dll and related PE files) channels headtracking into TrackIR-enabled and FreeTrack-compatible Windows applications. Install it into every Wine or Proton prefix where you need tracking. TrackIR firmware with companion files must be available on the Linux host (even if you are not using TrackIR hardware for tracking).

Command-line reference

Install from the shell: scripts/install/install_wine_bridge.sh <WINEPREFIX> <wine-binary>

The GUI copies bridge files from /opt/lib/linuxtrack/wine_bridge/, writes registry keys with wine reg, and links firmware DLLs into the prefix. The same payload is used by the shell script.

MFC42 without the Gaming tab

If you need MFC42 outside ltr_gui:

  • Debian/Ubuntu/MX (winetricks): WINEPREFIX=~/.wine winetricks mfc42
  • Fedora/RHEL/CentOS: sudo dnf install mfc42
  • Arch Linux/Manjaro: sudo pacman -S mfc42
  • OpenSUSE: sudo zypper install mfc42

Ubuntu/Debian/MX Linux do not ship MFC42 packages; prefer winetricks or the Gaming tab Install/Repair buttons.

Modern MinGW build system

LinuxTrack X-IR uses MinGW-w64 cross-compilation for real Windows PE binaries for Wine/Proton.

  • Real Windows artifacts: outputs are .exe and .dll PE binaries
  • Dual-prefix install: GUI/CLI detects 32-bit or 64-bit Wine prefixes and copies the correct PE files
  • Cleaner host dependencies: no winegcc-specific compile path required
  • Native Linux symlink handling: filesystem link creation stays on the Linux side

Built components

  • NPClient.dll - TrackIR API compatibility (32-bit)
  • NPClient64.dll - TrackIR API compatibility (64-bit)
  • FreeTrackClient.dll - FreeTrack API compatibility
  • Controller.exe - Hotkey control utility
  • Tester.exe / Tester64.exe - TrackIR testing utilities
  • ftc.exe - FreeTrack testing utility
  • TrackIR.exe - Fake TrackIR executable for games

Programs in the Wine prefix

After you install the Wine bridge into a bottle/prefix, several programs are available there:

Controller allows you to bind hotkeys to pause/resume and recenter the tracking. It can be minimized to the tray so it doesn't clutter the desktop. When a Controller is started, a window pops up and you should specify the pause key and recenter key - just press the appropriate button followed by key/keys of your choice (max 2 keys). The Controller only sees hotkeys inside the bottle/prefix where you installed it.

TrackIR is a fake TrackIR executable required by certain games in order to accept tracking data. It also loads the TIRViews library for older titles such as Battlefield 2, MSFS 2004/FSX, Richard Burns Rally, and similar.

FreeTrackTester, Tester (and on 64-bit Wine also Tester64) allow you to troubleshoot the Linuxtrack-Wine installation. If they work, the installation is OK.

To remove the bridge, delete the Linuxtrack folder under Program Files or Program Files (x86) in that prefix, and remove registry keys under NaturalPoint, Freetrack, and HKLM\SOFTWARE\Linuxtrack.

Supported games

Technically speaking, any FreeTrack and/or TrackIR enabled game/application should work. Directly tested titles include Microsoft Flight Simulator (2020, X), DCS World, IL-2 Sturmovik series, War Thunder, Elite Dangerous, Euro Truck Simulator 2, American Truck Simulator, Falcon AF, Condor Soaring simulator, and MSFS 2004.

If you know of others (working or not; assuming the game itself works under Wine), please let us know so the list can be updated.

Note on profiles

When the game/application is started for the first time, a new profile is created automatically by copying the default one. When adjusting the tracking in ltr_gui, be sure to select the correct profile first, otherwise you won't see any change.

The TrackIR software uses plus/minus 500 mm as a displacement limit, so to use the full displacement range, set the limits for translations accordingly (go to the Tracking Setup pane, select the appropriate profile, choose each translation axis in the axis list, and set the limit to 500 on the curve page).

Troubleshooting

  • Build errors: Ensure MinGW toolchains are installed and on PATH
  • Payload not found: Confirm /opt/lib/linuxtrack/wine_bridge/NPClient.dll exists after cmake --install
  • Artifact mismatch: expected outputs are .exe/.dll (not .exe.so/.dll.so)
  • Missing files: Verify all dependencies are installed (see README for details)

Verification steps:

  1. Check that MinGW toolchains are available: which i686-w64-mingw32-gcc x86_64-w64-mingw32-gcc
  2. Test the build process: cmake -S . -B build && cmake --build build -j$(nproc)
  3. Check generated files: look for .exe and .dll files in wine bridge build directories
