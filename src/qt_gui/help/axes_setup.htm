Tracking setup

When you have the tracking device and model set up, then you can proceed to the tracking customization.

Here you can set sensitivities, dead zones, response curves and filtration for each axis separately; you can also turn unwanted axes off, specify limits of each axis and so on. All this can be done separately for each target program/game. Axis curves and diagnostics are embedded directly in the Tracking setup tab.

Default profile

The Default profile is quite special - when an unknown game/program is run for the first time, the Default profile is copied over as a base of the new profile.

Profile header

Make sure you have selected the desired profile. The always-visible header lets you do the following:

  • Tracking rate (FPS) sets how often head pose and the camera preview in the Tracking window are updated each second (30–120 FPS; default 120). The value is saved per profile. Lower rates reduce CPU usage and how often games or clients receive pose updates; they do not change the camera hardware frame rate.
  • Common smoothing slider sets the amount of smoothing applied to all axes.
  • Copy from Default Profile copies Default profile setup to the current profile.
  • Restore axis defaults resets all axis settings on the current profile from your saved axis baseline (factory values until you use Save as axis defaults). Editing the Default profile or any profile autosaves to that profile only; it does not update the baseline unless you save it. Tracking rate is not changed.
  • Save as axis defaults stores the current profile's axis settings as the rollback baseline used by Restore axis defaults. This is separate from the Default profile used when new games are detected.
  • Import profile / Export profile (at the bottom of the tab) import or export the current profile from/to a file.

All the controls have immediate effect on the tracking, so you can directly see the impact of the change. Also note, that while it is possible to run ltr_gui in parallel with a client program/game, it is not recommended. The tracking does work without the GUI running, unlike other popular alternatives (NP, FreeTrack, FaceTrack NoIR...).

Axis curves

Below the header, select an axis from the list (Pitch, Yaw, Roll, and the three translations). The curve editor for that axis is shown in the center of the tab.

  • Enable and Invert on the curve page turn the axis on/off or reverse its response.
  • For both halves of an axis you can set an in-game Limit. The Symmetrical check-box allows you to unchain those halves and set each one separately.
  • Sensitivity changes how responsive the axis is. The higher the sensitivity, the smaller head movement will be necessary for tracking. Just be careful not to set it too high — it might result in a stiff neck, and other problems.
  • Per-axis Smoothing gives that axis additional filtration beyond Common smoothing.
  • The response graph lets you edit curve points (select a point to edit coordinates; remove interior points with the button, right-click, or Delete).

Diagnostics

  • Live pose (collapsible) shows measured, curved, and filtered values for each axis.
  • Pose maps sit in a collapsible column to the right of the curve editor (Look, Lean, Raise/Roll stacked vertically). Each map uses a dark plot with a center crosshair, teal guide rings, and a red flat-response region at the middle. That red area is the flat prefix of the response curves for the map's axes (near-zero output along the curve, e.g. Look uses yaw and pitch); editing those curve points updates the overlay. Teal rings are decorative guides out to the axis limits. A green dot shows the current measured or filtered position (selectable from the drop-down). When Pose maps are collapsed, use the Pose maps button next to Recenter to show them again.
  • Recenter recenters the current head pose.
  • Clip/Cap head-center (pan) tuning lives on the Model Setup tab, not here.
