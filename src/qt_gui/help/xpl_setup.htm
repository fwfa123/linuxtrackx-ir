X-Plane plug-in setup

When you have the X-Plane plug-in installed according to the X-Plane plug-in installation, a short setup is needed in order to use it - keyboard keys have to be bound in order to start, stop, recenter and pause the tracking. Please note, that the setup of tracking parameters (sensitivities, ...) is done in the Linuxtrack GUI, X-Plane plug-in doesn't have any means to do that.

Note: For X-Plane 12.0 with the latest SDK installed, there is no need for the PilotView plugin. Linuxtrack works directly with X-Plane's native head tracking interface.

Before You Begin

Start Linuxtrack First

Before launching X-Plane, you should open the Linuxtrack GUI and start the tracking server. This ensures that the tracking daemon is running and ready when the X-Plane plugin loads. Verify that tracking is working properly in the Linuxtrack interface before starting X-Plane.

Disable TrackIR in X-Plane

X-Plane has built-in TrackIR support that must be disabled for Linuxtrack to work properly. To disable it:

  1. Launch X-Plane and navigate to Settings
  2. Click on the Graphics tab
  3. Scroll down to the Visual Settings section
  4. Uncheck "Enable TrackIR & TrackHat view tracking in 3-D cockpit"

If this option is enabled, it will interfere with Linuxtrack's head tracking. Make sure it is unchecked before proceeding with the setup.

Keyboard bindings setup

In X-Plane 12, keyboard bindings are configured through the Keyboard tab in Settings. Follow these steps to assign keys to Linuxtrack commands:

  1. Navigate to Settings → Keyboard tab
  2. Use the search field or scroll down to find the linuxtrack section in the command list
  3. Expand the linuxtrack section if it's collapsed (click the "-" or "+" icon)
  4. Click the "+" button next to the command you want to assign
  5. Press the key or key combination you want to use for that command

Critical Commands: The most important commands to assign are:

  • Start/stop tracking - Toggles head tracking on and off (most important)
  • Recenter tracking - Resets the tracking center position (most important)

Optional Commands: You may also want to assign:

  • Pause tracking - Temporarily pauses tracking
  • Start tracking - Starts tracking (if you prefer separate start/stop)
  • Stop tracking - Stops tracking (if you prefer separate start/stop)

When you're done assigning keys, click Done to save your changes and close the Settings window.

Important: After starting a flight in X-Plane, you will most likely need to use your assigned hotkey to start tracking manually. The plugin does not always start tracking automatically.

Complete Setup Workflow

For a successful Linuxtrack setup in X-Plane 12, follow these steps in order:

  1. Start Linuxtrack: Open the Linuxtrack GUI application and start the tracking server. Verify that head tracking is working properly before proceeding.
  2. Launch X-Plane: Start X-Plane 12
  3. Disable TrackIR: Go to Settings → Graphics tab → Uncheck "Enable TrackIR & TrackHat view tracking in 3-D cockpit"
  4. Configure Keyboard: Go to Settings → Keyboard tab → Find the "linuxtrack" section → Assign keys to "Start/stop tracking" and "Recenter tracking" commands (at minimum)
  5. Start a Flight: Begin a flight in X-Plane
  6. Activate Tracking: Use your assigned hotkey to start tracking (if it doesn't start automatically)

Once setup is complete, you can control head tracking using your assigned keyboard shortcuts during flight. Use the recenter command whenever you need to reset your head position.
